C. AKTIVITAS 1

Eksperimen "10" + "20"

String Concatenation
eksperimen1.js JavaScript 
let a = "10";
let b = "20";
console.log(a + b);
Console Output: Klik tombol untuk melihat output...
Pertanyaan LKPD Jawaban Hira Abiguna R
Apa output program? "1020"
Mengapa hasil tersebut terjadi? Karena nilai "10" dan "20" diapit tanda kutip sehingga dianggap sebagai String (teks). Operator + pada String berfungsi menggabungkan teks (concatenation), bukan menjumlahkan secara matematika.
Apakah a dan b bertipe Number? Tidak. Variabel a dan b bertipe String karena ditulis menggunakan tanda petik dua ("...").
Uji sekarang. Apakah prediksimu benar? Jelaskan. Ya, benar. Saat kode dijalankan di console, hasil yang muncul adalah "1020" (penggabungan karakter "10" dan "20").

Temuan: Apa perbedaan String dan Number berdasarkan eksperimenmu?

String adalah tipe data berbentuk karakter atau teks yang selalu diapit tanda petik ("..." atau '...') dan tidak bisa dihitung secara aritmatika langsung. Sedangkan Number adalah tipe data angka murni tanpa tanda petik yang dapat digunakan untuk operasi matematika (penjumlahan, perkalian, pembagian, dll).

Type Conversion: Number()

G. Tantangan Mandiri

Program Hitung Nilai Rata-Rata

Konversi input Tugas, UTS, dan UAS menggunakan Number() dengan rumus (tugas + UTS + UAS) / 3.

Algoritma Saya (Hira Abiguna R):

  1. Meminta pengguna memasukkan nilai Tugas, UTS, dan UAS.
  2. Mengonversi ketiga input String tersebut menjadi tipe data angka menggunakan fungsi Number().
  3. Menghitung nilai rata-rata dengan rumus: rataRata = (tugas + uts + uas) / 3.
  4. Menampilkan hasil nilai rata-rata beserta predikat kelulusan ke layar.
hitung_nilai.js Solusi Tantangan 
let tugas = Number(prompt("Masukkan nilai Tugas:"));
let uts   = Number(prompt("Masukkan nilai UTS:"));
let uas   = Number(prompt("Masukkan nilai UAS:"));

let rataRata = (tugas + uts + uas) / 3;
console.log("Nilai Rata-rata = " + rataRata.toFixed(2));

Sangat Baik (A)

H. THINK PAIR SHARE

Diskusi & Pemahaman Konsep

1. Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung?

Karena fungsi prompt() selalu mengembalikan data bertipe String meskipun pengguna mengetikkan angka. Agar dapat dioperasikan secara matematis (seperti penjumlahan), nilainya wajib diubah ke Number terlebih dahulu.

2. Apa perbedaan "10" dengan 10?

"10" (dengan tanda kutip) adalah String yang diperlakukan sebagai teks biasa. Sedangkan 10 (tanpa tanda kutip) adalah Number yang memiliki nilai numerik untuk perhitungan matematika.

3. Apa yang terjadi jika lupa Number()?

Pada operasi penjumlahan (+), program tidak akan menjumlahkan nilai angkanya, melainkan menggabungkan teksnya (misal "10" + "20" menjadi "1020"), sehingga terjadi kesalahan logika (logic error).

Pair (Diskusi Pasangan):

Jawaban kami sama. Perbedaan biasanya hanya muncul pada penulisan variasi tanda kutip (petik satu '...' vs petik dua "...") atau cara membungkus fungsi Number() langsung saat prompt().

Share (Temuan Penting untuk Kelas):

Selalu periksa tipe data variabel menggunakan typeof ketika program perhitungan menghasilkan output yang aneh, dan biasakan melakukan konversi eksplisit dengan Number() untuk setiap input numerik.
