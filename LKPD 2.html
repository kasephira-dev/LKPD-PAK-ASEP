01

Aktivitas 1 - Prediksi Operator Aritmatika

let a = 10;
let b = 5;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
Operasi Prediksi Hasil Sebenarnya Status
a + b 15 15 ✅ Benar
a - b 5 5 ✅ Benar
a * b 50 50 ✅ Benar
a / b 2 2 ✅ Benar

Apakah prediksi kamu benar?

Ya, benar sepenuhnya.

Mengapa? Karena operator aritmatika dalam JavaScript mengikuti aturan matematika dasar: + untuk penjumlahan, - untuk pengurangan, * untuk perkalian, dan / untuk pembagian.

02

Aktivitas 2 - Eksperimen & Operator Modulus (%)

let a = 20;
let b = 4;
console.log(a + b); // 24
console.log(a - b); // 16
console.log(a * b); // 80
console.log(a / b); // 5
console.log(a % b); // 0
a + b 24
a - b 16
a * b 80
a / b 5
a % b 0

Apa yang kamu temukan?

Operator % dinamakan Modulus, yaitu operator untuk menghitung sisa hasil pembagian. Karena 20 dibagi 4 adalah 5 tanpa ada sisa, maka hasilnya adalah 0.

03

Aktivitas 3 - Input dengan prompt()

let nama = prompt("Masukkan nama:");
console.log(nama);
let umur = prompt("Masukkan umur:");
console.log(umur);

Apa fungsi prompt()?

Fungsi prompt() berguna untuk menerima masukan (input) teks dari pengguna melalui sebuah kotak dialog (pop-up) di browser. Hasil input tersebut kemudian disimpan ke dalam variabel.

05-07

Mesin Kasir Mini & Warung Digital + Diskon 10%

Program simulasi kasir sederhana dengan input barang, harga, jumlah, serta perhitungan diskon 10%.

let makanan = prompt("Nama makanan:");
let harga = Number(prompt("Harga:"));
let jumlah = Number(prompt("Jumlah:"));

let total = harga * jumlah;
let diskon = total * 0.10; // Diskon 10%
let totalBayar = total - diskon;

console.log("Makanan:", makanan);
console.log("Total:", total);
console.log("Diskon:", diskon);
console.log("Total Bayar:", totalBayar);

Aktivitas 6 - Think Pair Share (Mengapa butuh variabel total?)

Jawaban: Variabel total dibutuhkan untuk menyimpan hasil perkalian awal antara harga dan jumlah barang. Hal ini memudahkan kita jika ingin menggunakannya kembali untuk perhitungan selanjutnya (seperti menghitung diskon dan total bayar) tanpa harus menghitung ulang harga * jumlah berkali-kali.

08

Aktivitas 8 - Debugging Kode Error

❌ Kode Error / Salah:
let harga = 5000;
let jumlah = 3;
let total harga = harga * jumlah;
console.log(total harga);
✅ Perbaikan Kode:
let harga = 5000;
let jumlah = 3;
let totalHarga = harga * jumlah;
console.log(totalHarga);

Analisis Kesalahan:

Nama variabel total harga menggunakan spasi. Di JavaScript, nama variabel tidak boleh mengandung spasi. Penulisan yang benar bisa menggunakan format camelCase (totalHarga) atau underscore (total_harga).
